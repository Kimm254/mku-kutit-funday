MKU KUTIT FUNDAY WEBSITE

1. Extract this ZIP file.
2. Open the extracted MKU_KUTIT_Funday_Website folder.
3. Open a terminal in this folder (right-click an empty area > Open in Terminal).
4. Install the requirements:
   py -m pip install -r requirements.txt
5. Start the website:
   py app.py
6. Open this address in your browser:
   http://127.0.0.1:5000

The website includes the MKU Graduation Square venue, KSh 200 entry fee,
activities and a registration form.

IMPORTANT: The form is a starter only. It does not send a real M-Pesa STK Push
or collect payment yet. Real payments require Safaricom Daraja credentials,
a public HTTPS callback URL, and further payment integration and testing.
Do not enter real payment credentials into public code or share your M-Pesa PIN.
